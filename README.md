# TokDesk

TokDesk uses TikTok Login Kit and the Display API. The browser page and OAuth callback must be served by the same HTTPS Node.js service.

## Deploy on Render

1. In Render, create a Blueprint from the public repository `https://github.com/asd00asdzz/-coa`.
2. Select the `main` branch and let Render read `render.yaml`.
3. Enter the TikTok Client Key and a newly rotated Client Secret when Render prompts for them. Keep secrets in Render environment variables; never commit `.env`.
4. Wait for the service to become Live, then open `https://<service-host>/api/status`. Check that `configured` is `true` and copy the returned `redirectUri`.
5. In TikTok for Developers → TokDesk → Login Kit → Redirect URI, register that exact HTTPS URI. It must match the callback generated by the server.
6. Open the Render service root URL and use **เชื่อมบัญชี TikTok**. Sign in to TikTok and grant the requested scopes.

Render provides `RENDER_EXTERNAL_URL`; the server uses it to build the callback URL. It also serves the app, privacy page, terms page, and TikTok URL-verification file from the same origin.

## Local run

Use Node.js 22.18 or newer:

```sh
npm start
```

For local configuration, create an untracked `.env` with `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, and `PUBLIC_URL`. The web Login Kit callback still requires a public HTTPS URL registered in TikTok.

## Storage note

The free Render service is intended for testing. Its filesystem is temporary, so `tokens.json` can be lost when Render restarts the service. Reconnect TikTok after a restart. Persistent storage requires a separate durable datastore or a paid persistent disk.
